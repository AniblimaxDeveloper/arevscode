# arevscode roadmap

## v0.1.0 foundation
- [x] Modern dark IDE shell
- [x] Responsive rail/bottom navigation
- [x] SAF workspace picker
- [x] Text editor and save
- [x] Android shell terminal
- [x] Copilot Gemini integration
- [x] GitHub Actions APK build
- [x] GitHub/Git UI foundation

## v0.2.0 coding engine
- [ ] Syntax highlighting for Kotlin, Java, XML, JSON, JS/TS, Python, HTML/CSS, Markdown
- [ ] Multi-tab editor
- [ ] Search in file / search in workspace
- [ ] Code folding, bracket matching, autocomplete
- [ ] Undo/redo history and file watcher
- [ ] Diff viewer

## v0.3.0 developer platform
- [ ] Real Git implementation (JGit)
- [ ] GitHub OAuth/device flow
- [ ] Clone, branch, commit, push, pull, diff, PR UI
- [ ] Project templates
- [ ] Android/Gradle project runner
- [ ] Build output parser and clickable diagnostics

## v0.4.0 terminal platform
- [ ] Persistent PTY sessions
- [ ] Multiple terminal tabs
- [ ] Environment/package manager UI
- [ ] Optional embedded Linux engine
- [ ] Optional Termux bridge

## v0.5.0 agentic Copilot
- [ ] File/workspace context selector
- [ ] Safe patch preview
- [ ] Apply/reject/revert changes
- [ ] Error-log ingestion
- [ ] Build/test/fix loop
- [ ] Tool permission gates
- [ ] Project-wide indexing
- [ ] Offline/local model adapter
